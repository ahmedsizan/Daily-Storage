# Daily Storage - Fullstack Cloud Notepad (TypeScript + Supabase)

`Daily Storage` হলো একটি সিকিউর, প্রাইভেট এবং ক্লাউড-বেসড নোটপ্যাড অ্যাপ্লিকেশান। এতে **Supabase Auth** এবং **Row Level Security (RLS)** ব্যবহার করা হয়েছে, যাতে প্রত্যেক ব্যবহারকারী শুধুমাত্র তার নিজস্ব সংরক্ষিত নোট দেখতে, লিখতে, পিন করতে, এডিট ও মুছতে পারেন।

## 🚀 ১. ডাটাবেজ সেটআপ (Supabase)

1. আপনার [Supabase Dashboard](https://supabase.com/dashboard)-এ যান এবং প্রজেক্ট সিলেক্ট করুন।
2. বাম পাশের মেনু থেকে **SQL Editor** এ ক্লিক করুন।
3. **New Query** সিলেক্ট করুন।
4. [schema.sql](file:///d:/Experiment_with_antigrabity/1st_backend_conect_project/schema.sql) ফাইলের কোডগুলো পেস্ট করে **Run** বাটনে চাপুন (এতে অটো-কনফার্ম ট্রিগার যুক্ত রয়েছে)।

### ✉️ Email Confirm অপশন অফ করার নিয়ম (Supabase Dashboard থেকে):
1. Supabase Dashboard থেকে **Authentication** -> **Providers** এ যান।
2. **Email** প্রোভাইডারে ক্লিক করুন।
3. **"Confirm email"** অপশনটির সুইচটি **OFF (Disable)** করে দিন।
4. **Save** এ ক্লিক করুন।

> [!TIP]
> এটি অফ করলে যেকোনো ইউজার অ্যাকাউন্ট তৈরি করার সাথে সাথে কনফার্মেশন ছাড়াই সরাসরি লগইন হয়ে যাবে। একই সাথে Supabase-এ প্রতি ইমেইলের জন্য ইউনিক ভ্যালিডেশন সক্রিয় থাকে, তাই একটি ইমেইল দিয়ে দ্বিতীয়বার কখনোই নতুন অ্যাকাউন্ট খোলা সম্ভব হবে না।

## 💻 ২. ফ্রন্টএন্ড রান করার নিয়ম

### পদ্ধতি ক: VS Code Live Server বা যেকোনো লোকাল সার্ভার দিয়ে
কোনো অতিরিক্ত প্যাকেজ ইনস্টল ছাড়াই সরাসরি যেকোনো ব্রাউজার দিয়ে `index.html` ফাইলটি একটি লোকাল সার্ভারে ওপেন করলেই চলবে:
- VS Code-এ **Live Server** এক্সটেনশন থাকলে `index.html` এ রাইট ক্লিক করে **Open with Live Server** দিন।
- অথবা পাইথন দিয়ে: `python -m http.server 3000`

### পদ্ধতি খ: Node.js / Vite দিয়ে
Node.js ইনস্টল থাকলে:
```bash
npm install
npm run dev
```
তারপর ব্রাউজারে `http://localhost:3000` ওপেন করুন।
